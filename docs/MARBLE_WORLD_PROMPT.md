## Paste into Imagine a world
> Create a coherent, navigable coastal kitchen and living room for The Edge Kitchen. Follow the attached floor plan as the layout authority. Use warm walnut, ivory stone, bronze details and soft daylight. Corner glazing overlooks an Uluwatu-inspired cliff, ocean and surf. Place the round dining table beside the glazed corner. The central island sits diagonally, with four induction zones and one central gas burner at one end, preparation space in the middle, and a single sink at the other. Keep a generous, clearly visible walkway between the island and sofa. Preserve the floor plan's positions for the twin refrigerators, ovens, utensil storage, sofa, long coffee table, television and elevated glass-door cooking hearth. Add discreet herbs and minimal decoration. Keep the room empty, with no people or text. Prioritize consistent geometry and natural proportions.

## Reference input
1. Orient the creator's hand-drawn floor plan with the labels upright. Its layout takes precedence over contradictory generated views.
2. Select one approved daylight overview as the main visual reference. Add only compatible alternative views where Marble's current input supports them; use the floor plan as a layout aid if supported, not as a photographic view.
3. Exclude rejected island orientations, compressed sofa clearances and inconsistent furniture placement. Do not submit all ten images automatically, or mix day and night states as though captured together.
4. Record selected filenames, versions and checksums in an asset manifest before the first generation. A source bundle exists from earlier iterations, but it contains superseded views and is not an approved input manifest.
5. Review the result from multiple camera positions: island angle, sofa clearance, table access, glazing corner, appliance locations, TV/hearth adjacency and material continuity. Save the accepted world/export reference and camera positions.

## Limits and later motion
Generated images are independent samples, not synchronized multiview evidence. Marble may infer unseen geometry; inspect it rather than assuming exact reconstruction. A navigable world is not necessarily an editable, correctly scaled, rigged Blender scene.

Add waves, moving surfers, cooking actions and any avatar in a separate tested production step. Do not rely on a static world to produce those motions. Preserve the scene's geometry across later video generation.
